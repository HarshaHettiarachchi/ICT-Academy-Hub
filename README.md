# ICT Academy Hub

## App Description

ICT Academy Hub is a modern web development learning platform built using React and TypeScript.

The application helps users learn web development concepts from beginner to advanced levels through structured lessons, learning resources, and practical project examples.

Users can explore development roadmaps, view open-source projects, search learning resources, and submit questions through a validated form.

The project demonstrates modern frontend development practices including React components, routing, API integration, state management, form validation, and responsive UI design.

---

## Technologies Used

- React
- TypeScript
- Vite
- React Router DOM
- TailwindCSS
- Context API
- Formik
- Yup
- TanStack Table
- REST API

---

## Features

### Learning Dashboard
- Hero section with introduction
- Web development roadmap
- Learning categories
- Responsive design

### Lessons Page
- Beginner to advanced web development lessons
- Structured learning cards

### Projects Page
- Fetches repository data from GitHub API
- Displays data using TanStack Table
- Search/filter functionality

### Resources Page
- Learning resource library
- Search resources
- Category filtering

### Ask Question Page
- Form submission
- Form validation using Formik and Yup

### Theme System
- Light/Dark mode switching
- Theme preference saved using Local Storage
